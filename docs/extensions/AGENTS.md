# Extensions Documentation DOX

## Purpose

- Own trusted executable-extension and hook documentation.

## Local Contracts

- Document extensions as explicitly installed Git repositories with declared executable hooks that receive bounded JSON over standard streams and run from their repository directory.
- Document at-least-once hook delivery with a stable `event_id`, per-extension receipts, persistent consumer deduplication of visible effects, and the exact-once disclaimer for arbitrary side effects.
- Document the three restart-bound extension controls and the live apply of every other exposed setting.
- Review extension repositories before installation is required product guidance.
