# Guides Documentation DOX

## Purpose

- Own step-by-step user guidance: first engagement, installation, troubleshooting, and recovery.

## Local Contracts

- Keep the getting-started guide focused on installation and launch commands plus platform/prerequisite requirements. Supported platforms are macOS and Linux; do not make Windows caveats or promises.
- Narrate installer progress and PATH mechanics in the getting-started guide, never in the root README.
- Troubleshooting must offer offline checks first, then bounded live diagnostics, and must never instruct users to delete fresh leases or infer success from silence.
- Validate every command and example against executable behavior before documenting it.
